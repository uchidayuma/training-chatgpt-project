# SNSプラットフォーム別 投稿ルール

## X（旧Twitter）

| 項目 | 内容 |
|---|---|
| 文字数制限 | 140文字（日本語）／280文字（英語） |
| 推奨ハッシュタグ数 | 1〜2個 |
| 絵文字 | 1〜2個まで（ビジネス投稿の場合） |
| 向いている内容 | 短いノウハウ・速報・問いかけ・共感系 |
| 書き出しの鉄則 | 最初の1文で「続きを読みたい」と思わせる |

## LinkedIn

| 項目 | 内容 |
|---|---|
| 文字数制限 | 3,000文字（投稿）／220文字（プレビュー表示） |
| 推奨ハッシュタグ数 | 3〜5個 |
| 絵文字 | 最小限（見出し・区切りとして1〜3個） |
| 向いている内容 | 業務ノウハウ・キャリア・採用・事例・実績 |
| 書き出しの鉄則 | 最初の2行（プレビュー部分）に結論か問いかけを入れる |
| 改行ルール | 2〜3行ごとに空行を入れて読みやすくする |

## Instagram

| 項目 | 内容 |
|---|---|
| 文字数制限 | 2,200文字 |
| 推奨ハッシュタグ数 | 5〜10個（ビジネス向けは少なめに） |
| 絵文字 | 積極的に使用OK |
| 向いている内容 | ビジュアル訴求・ブランディング・イベント・採用 |
| 書き出しの鉄則 | 画像と連動した書き出し。「〇〇な写真の裏側は…」など |

## プラットフォーム共通の鉄則

1. **書き出しが命**：最初の1〜2行で読者を引き込む
2. **CTAは1つだけ**：「いいね・シェア・リンク・コメント」を同時に求めない
3. **数字を使う**：「業務効率化できます」より「週3時間の削減に成功」
4. **自分ごと化**：読者が「これは自分のことだ」と感じる表現を使う

## トーン別の文体サンプル

| トーン | 書き出し例 |
|---|---|
| プロフェッショナル | 「〇〇業界で見落とされがちな課題があります。」 |
| 親しみやすい | 「正直に言います。〇〇って、思ったより難しいですよね。」 |
| 問いかけ | 「あなたのチームでも〇〇に時間をとられていませんか？」 |
| 実績訴求 | 「〇〇を導入して3ヶ月。変わったのは数字だけではありませんでした。」 |
